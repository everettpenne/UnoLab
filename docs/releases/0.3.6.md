# Uno Lab 0.3.6

The assistant gesture opens search over the app, not back on the Home screen.

## What's changed

- **The hand-off aims at Uno Launcher's floating search window** (`.search.AssistActivity`) instead of the Home activity, so the panel appears over whatever app is in front and closing it returns you there.
- **Older launchers still work**: it falls back to the Home activity (today's behaviour, which takes you Home), and then to Uno Lab itself.
- The screen's text travels the same way it did — in the hand-off — and is only read when a question asks about the screen.

## Install

Download `UnoLab-0.3.6.apk` and check it against `SHA256SUMS.txt`. Pair it with Uno Launcher 0.132.3-uno01 for the floating window.

## Notes

The gesture → floating search hand-off **was not tested on a device for this release**: the phone was off the network when it was built. The launcher half (the floating window itself) is where the risk is; this app only changes which activity it names.
