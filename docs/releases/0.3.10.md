# Uno Lab 0.3.10

Answers and follow-ups are the model's own again: the planner's training is now an add-on used only while a plan is written, for the conversations in Uno Launcher 0.134.0 and later.

## What's changed

- **The planner is an adapter beside the model, not merged into it.** A planner trained for Uno Launcher's tasks can be dropped in as a LoRA file (`*.lora.gguf`) next to the stock model. Uno Lab puts it on only while it writes a plan and takes it off for everything else, so answers in search and the chat come from the stock weights.
- **Why.** Merged into the weights, the planner's training made ordinary answers worse. Asked "where did he live" after "who painted the starry night", the merged model replied "I don't have a person in mind" for 22 of 24 follow-ups; the stock model got 24 of 24. With the adapter kept apart, answers are 24 of 24 and plans score as the merged model's did (17 of 17 follow-ups to a task, 56 of 57 fresh requests).
- **Putting one in.** Push the adapter to the same folder as a model; it is moved in when Uno Lab loads. One adapter is kept at a time. Moving in a new model drops the adapter that was there, since an adapter only fits the weights it was trained on; one that does not fit is ignored and plans use the model alone.
- With no adapter, nothing changes from 0.3.9.

**The planner adapter is with this release:** `planner-v4.lora.gguf` (33 MB). It fits the stock Qwen3.8-2B model only (tested with the Q4_K_M file); keep its name ending in `.lora.gguf` so Uno Lab takes it for an adapter. No model is included. Its SHA-256 is:

```text
84ef478e86089ef0598f40df4069e94e10cce544e1e83411588dfbca8f5258d6
```

## Tested

On a Pixel 10a, with the signed 0.3.10 build, the stock Qwen model and a 33 MB planner adapter: both loaded in 3.5 s. From Uno Launcher's test build, "who painted the starry night" then "where did he live" was answered with where Van Gogh lived, and "set a timer for 5 minutes" then "make it 10 minutes" gave a plan for a 10-minute timer. The first plan after loading took about 50 s while the list of tools was read; later ones about 13 s.

On an emulator, the new device test passed: the follow-up was answered from the stock weights, a timer plan was written with the adapter on, and the next answer was the weights' own again.

The scores above (24 of 24 answers, 17 of 17 and 56 of 57 plans) are from the training project's evaluation scripts with the same model and adapter, not from this app.

**Not tested:** an adapter that does not fit the model, and replacing the model while an adapter is in place.
