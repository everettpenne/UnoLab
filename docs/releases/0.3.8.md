# Uno Lab 0.3.8

The assistant gesture opens Uno's search over the app you're in.

## What's changed

With Uno Launcher 0.132.5 or later, the gesture now goes to the launcher's search shown **over the current app** instead of to Home's search, so Back returns you to the app. With an older launcher it still opens Home's search, as 0.3.7 did, since older launchers' floating search could crash. The screen's text still travels with it for a question about the screen.

## Install

Download `UnoLab-0.3.8.apk` and check it against `SHA256SUMS.txt`. Signed with the same key as 0.3.7, so it installs over it.
