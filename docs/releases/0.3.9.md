# Uno Lab 0.3.9

Faster answers in Uno's search, and a planner for Uno Launcher 0.133.0's tasks.

## What's changed

- **Answers are written about 75% faster from Uno's search.** Measured on a Pixel 10a, asking from search with Uno Lab in the background:

  | | reading the question | writing the answer |
  |---|---|---|
  | 0.3.8 | 28 to 38 tokens/s | 4.9 to 5.1 tokens/s |
  | 0.3.9 | 44 to 58 tokens/s | 7.7 to 10.3 tokens/s |

  Two causes. The model's threads were made afresh for every token; they now live in a pool. And Android lets a background app use only three of this phone's four fast cores, so a fourth thread ran on a slow core and every step waited for it; Uno Lab now uses one thread for each fast core it is allowed at that moment (three in the background, four when Uno Lab itself is in front).
- **A planner for Uno Launcher's tasks** (assistant API version 2). With **Let Qwen do tasks** on in Uno Launcher 0.133.0, the launcher sends the request with the list of things it can do, and Uno Lab replies with a plan as JSON, held to that shape by a grammar. Uno Lab still only plans: it has no network access and does nothing on the phone itself; the launcher checks the plan and carries it out. The list travels with each request, so a new launcher capability needs no new Uno Lab.
- A plan is not written to the phone's log (it carries what was asked for). A test can turn that on with `adb shell setprop log.tag.UnoLabPlan DEBUG`.
- The thread settings can be overridden for measuring with `adb shell setprop debug.unolab.threads` (also `tbatch`, `pool`, `poll`, `prio`).

## Tested

On a Pixel 10a: the speeds above, each setting run twice with the same questions, with the settings switched over adb in one build; the phone warmed from 32 to 38 °C over the runs, and the 0.3.8 settings re-run at the end still gave 4.9 tokens/s. With Uno Launcher's test build, 48 task phrasings were planned (37 as expected), at a median of about 7 seconds a plan after the first.

**Not measured:** the speed with the final defaults in this exact build (the figures are from the same code with the settings chosen over adb), and the speed with Uno Lab itself in front.
